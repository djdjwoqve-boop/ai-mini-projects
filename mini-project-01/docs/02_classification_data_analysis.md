## 2. 계층화 데이터 분할 (CP-02)

**분석:** Train·Validation·Test의 구매 비율이 유사한지 확인하고 의미를 1~2문장으로 작성합니다.

## 4. 데이터 전처리 및 PyTorch 입력 준비 (CP-03)

- **범주형 특성(One-Hot 인코딩):** 6
- **수치형 특성(표준화):** 10
- **이진 특성(변환 없이 사용):** 1
- **숫자로 표현된 코드값(`OperatingSystems`, `Browser` 등)을 범주형으로 처리한 이유:** 여기서 숫자는 단순히 분류코드인데 실제 수치가 중요한 숫자처럼 다루면 이상해지기 떄문입니
- **`handle_unknown="ignore"`를 설정한 이유:** 범주가 벗어라도 0으로 처리할려고입니
- **Train 전처리 전후 Shape:** (8630, 73)
- **Validation에 적용한 변환 기준:** (8630, 73)
- **PyTorch 입력·타깃 Tensor의 자료형 및 Shape:** Tensor: torch.Size([8630, 73]) torch.Size([8630])
- **`DataLoader` 배치 크기와 배치 수:** 256 /33

**분석:** 신경망 입력을 `float32` Tensor로 준비하고 미니배치를 만드는 이유를 1~2문장으로 작성합니다.  

미니배치는 전체 학습 데이터를 한 번에 다 처리하지도 데이터를 한개씩 처리하는 것이 아닌 적당한 크기로 쪼갠 데이터 묶음입니다. 상황에 맞게 쓰기 위해서입니
