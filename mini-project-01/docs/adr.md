## 1일차 — 회귀 (공유자전거 대여 수요 예측)

### 의사결정 ① 입력 특성 선택 (CP-02)

**문제**

검토한 선택지: casual·registered 포함 여부, atemp 유지 여부, 상관이 낮은 windspeed 제거 여부, instant·dteday의 입력 사용 여부
최종 선택(사용·제외한 특성): season, yr, mnth, hr, holiday, weekday, workingday, weathersit, temp, hum, windspeed 11개를 사용하고, CP-03에서 is_commute_hour를 추가했다. casual, registered, atemp, instant, dteday는 제외했다 (cnt는 타깃).
선택 근거(누수 확인, 예측 시점, 상관관계 등): 전 행에서 **casual + registered == cnt**가 성립해 두 변수를 제외습니다. temp와 atemp의 상관계수가 0.992여서 temp만 사용했는데 만약에 상관계수가 높아도 좋다면 아마도 저희가 보는 특징들은 복잡 번다할텐데 제가 보아온 그래프는 그러하지 않으니 상관계수가 높은 것을 중복하면 안좋은 거라고 유추가능합니다
- **감수한 한계 또는 추후 확인할 점:**모르겠습니다.

**분석 근거:** `01_regression_data_analysis.md`

### 의사결정 ② 최종 회귀 모델 선택 (CP-07)

**문제**

서로 다른 회귀 모델 및 설정 중 하나를 최종 모델로 선택해야 합니다.

- **비교한 모델·설정:** Dummy(mean), LinearRegression, DecisionTree(max_depth=3/6/12), RandomForest A(n_estimators=50, max_depth=10)·B(n_estimators=100, max_depth=15). CP-07에서는 RF-B와 Tree-12의 시간대별 오류도 비교했습니다
- **최종 선택한 모델·설정:** 랜덤 포레스트 B
- **선택 근거(Validation MAE, 과대적합 가능성, 시간대별 오류 등):** 64,모델중에서 낮은걸로 기억합니다.출퇴시간에 오류가 증가했습니다. 
- **선택 모델의 장점:** 결정트리와 다르게 여러 트리를 사용해서 개선해서 비교 모델중에서 지표가 제일 좋았습니다.
- **남아 있는 한계 또는 개선 방향:**계절별 고려는 필요합니다.

## 2일차 — 분류 (온라인 쇼핑 구매 여부 예측 · PyTorch MLP)

### 의사결정 ③ 평가 지표 선택 (CP-04)

**문제**

구매 세션이 전체의 약 15%뿐인 불균형 데이터이므로, Accuracy만으로 구매 클래스를 얼마나 잘 예측하는지 판단하기 어렵습니다.

- **검토한 선택지:** 구매,비구매 클래스의 비율이 차이가 나서 균형 조정 (예: Accuracy, 구매 클래스 F1, Precision, Recall)
- **최종 선택한 주 지표와 보조 지표:** Recall,F1
- **선택 근거(DummyClassifier와 LogisticRegression 결과, FP·FN 등):** 이경우는 미구매가 구매보다 많기 때문에 단순히 더미로 측정해도 정확도는 높습니다. 근데 재현율과 F!이 낮기 때문에 재현율을 위주로 관측하기로 결정했습니다.
- **감수한 한계 또는 추후 확인할 점:** 잘 모르겠습니다. 

**분석 근거:** `02_classification_data_analysis.md`, `02_classification_model_analysis.md`

### 의사결정 ④ PyTorch MLP 설정 및 분류 임계값 선택 (CP-07)

**문제**

기본 손실 함수로 학습한 MLP-A와 클래스 가중 손실을 적용한 MLP-B를 비교하고, 구매 확률을 0/1로 구분하는 임계값(0.3·0.5·0.7)을 선택해야 합니다.

- **검토한 선택지:**  임계값,가중손실 적용여부 (MLP-A / MLP-B의 학습 결과, 임계값 0.3·0.5·0.7)
- **최종 선택한 MLP 설정·임계값·재학습 에포크:** B 임계값 0.7 17
- **선택 근거(Validation F1, Precision·Recall, FP·FN 및 가중 손실의 영향):** 이때 B의 결과는 	MLP-B (weighted BCE)	0.7	0.647	0.647	0.647	101	101입니다.
다른 모델과 비교해서 F1-score가 가장 높고 정밀도,재현율이 동일하여 균형이 좋습니다. 
또한 FP,FN이 각각 101건으로 두 오류의 개수가 같다는 점이 이 모델의 선택을 결정한거 같습니다 
- **LogisticRegression과 비교했을 때 선택한 MLP의 특징:** 로지스틱이 F1 Gap이 적어서 일반화 성능이 좋다는 장점 말고는 여러가지 지표에서 많이 밀립니다.
- **감수한 한계 또는 추후 개선 방향:** 여기서 선택한 최적 모델이라 하더라도 정확도,재현율,정밀도,F1스코어는 업계에서 사용하기에는 많이 부족한 것 같습니다.
이러한 것의 원인은 추측하기로는 데이터 불균형이 심한데 이를 보완할 특성이 부족해서 그러지 않을까 싶습니다. 모델 개선은 잘 모르겠습니다.


**분석 근거:** `02_classification_model_analysis.md`
